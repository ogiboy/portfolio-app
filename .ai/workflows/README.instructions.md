# Project Workflows

These workflows explain how to perform bounded work. They do not alter the authority order or grant external-write authority.

- `feature-workflow.instructions.md`: local feature and bug work.
- `browser-qa-workflow.instructions.md`: rendered public-journey verification.
- `security-workflow.instructions.md`: security inspection and disclosure boundaries.
- `release-pr-workflow.instructions.md`: PR, preview, merge, and production reconciliation.
- `external-tooling-policy.instructions.md`: tools, hosted state, and external-write boundary.
